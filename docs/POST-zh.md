## 正文

**《NBA 2K13》Xbox 360 版 → Switch 原生移植**（不是模拟器）

做法是静态重编译 + 原生 Vulkan 渲染器：把 `default.xex` 的 PowerPC 代码翻成 C++，Switch 上编译成原生程序；
GPU 那边不进模拟，直接读游戏写给显卡的命令环，用 Vulkan 画同一帧。渲染器是从 NFSMW-NX 那套移植过来的。

**现在是能玩的**：能进比赛、能打完整场、掌机模式大部分时间 30 帧、拆开 Joy-Con 能本地双人、赛前 MV 和回放能放、
记分牌和水印都在、有声音。

**但没做完，我想找人接手。** 剩下这些都是渲染器的活儿，不是搬砖的活儿，我一个人推不动了。我把知道的全写下来了，
接手不用从零开始。

### 已经能玩的

- 进游戏 → 主菜单 → 选项 → 训练 → 整场比赛，全程能走完
- 掌机模式大部分时间 **30 帧**
- 赛前 MV、回放、球员特写
- HUD、记分牌、2K13 水印
- 音频（XMA 在机器上解）
- **拆 Joy-Con 本地双人**
- 原生渲染器每帧处理约 900 次绘制，每次 1.5–1.8 µs

### 还坏的

| 问题 | 查到哪一步了 |
|---|---|
| **部分场馆木地板整片发黑** | 电脑上也复现，所以是渲染器的问题。已经排除：子区域取样、resolve 裁剪、mipmaps、读深度的那步光照、阴影缩放。特征是木纹没了但三秒区刷的漆还在、球场边线到黑块边缘就断 —— 说明是画地板自己那一步错了，不是上面盖了东西。下一步：用"跳过指定着色器"的开关二分，配像素统计来定。 |
| **技术统计页头像碎片** | 选项菜单那处已经修好，统计页这处没有。它采样的纹理落在别人的 resolve 里，而且格式是 resolve 永远产不出来的压缩格式，等于把 CPU 写进去的字节当像素读了。下一步：把那块的格式和地址打出来，在 CPU 侧正确解码。 |
| **赛前 MV 仍是两层画面** | 已经找到并修掉一个原因（兜底逻辑拿场景中间图当画面呈现），日志确认修的那条在起作用，但重影还在 —— 说明还有第二条路径。残留的接缝形态像"640×360 的层被放大塞进一个象限"。 |
| **个别菜单文字被裁**（`THUNDER` 变 `UNDER`） | 基本可以确定是"声明尺寸小于 resolve 的纹理会被裁剪"这条规则波及到了字体图集。 |
| **菜单音频轻微卡顿** | 线程优先级已经提过了，剩下要靠测，不能靠猜。 |
| **比赛有段落掉到 20 帧** | CPU 100% 和 GPU 99.7% 同时出现，需要看性能断面分清主次。 |

**60 帧做不到**，这是量出来的不是猜的：模拟 Xenos 每次绘制要 ~80 µs CPU，900 次绘制就是 72 ms 一帧，
天花板 12 帧。原生渲染器是 1.5–1.8 µs，所以这条路才有 30 帧。

### 接手的人能拿到什么

- **49 个补丁的完整账目**：每个都有现象、根因、做法、状态、判据。**包括我搞错的 5 个**（已经回退，理由都写着），
  省得你重走。
- **一套能用的取证流程**：脚本化按键把游戏推到固定的界面，渲染器能把任意渲染目标导成 PNG，
  分析脚本把 PNG 变成数字。不靠"看着像没问题"。
- **游戏内调试面板**（Switch 上 `L3+R3+十字键右`）：每个补丁都能运行时开关，改一个参数不用重新编译就能看效果。
- **一个必须知道的坑**：我曾经为了省 16 MB 去动了物理内存分配器，结果游戏越界写踩坏数据，赛前 MV 每次都卡死。
  账本里有完整过程 —— 靠的是"拿上一个正常包的日志做差异对比"，两行 `[PHYSPAD]` 就能一眼定案。

### 技术细节（简述）

- **ReXGlue** 负责把 PowerPC 翻成 C++，并给它一个 360 的环境（文件、内存、线程、音频）。
- **不模拟 Xenos**：读游戏写进 PM4 命令环的东西，用 Vulkan 画同一帧。渲染目标是普通 image，resolve 变成拷贝，
  下一次游戏要 clear 的直接两张图交换。
- **游戏用的是 2008 版着色器容器**（`0x102A1100`），上游几个移植项目都没有这套：头长度不一样、微码偏移不一样，
  而且顶点着色器的 fetch 常量已经被 D3D 改写过 —— 精确哈希配不上，最后靠"差异全落在 fetch 指令那三个字里"的
  位置规则才配上。着色器库 7,380 个。
- **剩下的 bug 大多同一个主题**：游戏反复把同一段 guest 内存当渲染目标、当纹理、再当另一个渲染目标，
  每次身份变化都是一次"可能采到错字节"的机会。
