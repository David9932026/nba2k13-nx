# 06 · 构建指南

---

## 1. 环境

| 项 | 值 |
|---|---|
| 构建机 | Windows 10（本项目在一台 4 核笔记本上做的） |
| 构建环境 | MSYS2，`ucrt64` 工具链 |
| 交叉编译 | devkitPro（`/opt/devkitpro`） |
| 生成器 | CMake + Ninja |

`switch-build/build-sw.sh` 是实际在用的构建脚本，内容很短：

```bash
export PATH=/ucrt64/bin:/usr/bin:/opt/devkitpro/tools/bin:$PATH
export DEVKITPRO=/opt/devkitpro
B=<工程根>/rex/nba2k13app/out/build/sw
cmake --build $B -j 6 -- -k 50
echo BUILD_EXIT=$?
```

要点：**先 `cd` 到工程根再调它**（脚本里的输出目录是绝对路径，但 CMake 的配置步骤在根目录跑）。
`-k 50` 是"错 50 个才停"，因为常见情况是一处改动引发一片编译错误，一次看完再修。

## 2. PC 构建（`win-vk`）

PC 构建是**主力开发环境** —— 一次编译十几秒，能直接跑、能截图、能逐像素比对。
所有修复都先在 PC 上验证，再上 Switch。

```bash
bash pcb.sh          # → out/build/win-vk/nba2k13.exe
```

运行需要把 Vulkan 驱动指到软件/系统实现：

```powershell
$env:REX_VK_ICD = "nvaci\nvoglv64.dll"
```

自动跑一段并抓帧：

```powershell
.\nativo-run.ps1 -Seconds 120 -Script input-menu.txt -Tag trial `
                -Extra "--NBA2K13_captura_cada_s=4 --NBA2K13_captura_max=70"
```

- `-Script input-*.txt`：脚本化的按键序列（毫秒时间戳 + 按键），用来复现"进比赛/进技术统计"这类路径
- `-Tag`：给这一轮的日志和截图目录打标记
- `-Extra`：额外的 cvar，**空格分隔**

## 3. Switch 构建与上卡

```bash
cd <工程根>
bash switch-build/build-sw.sh       # → rex/nba2k13app/out/build/sw/nba2k13.nro
```

上卡（SD 挂载为 `F:`，卷标 `SWITCH`）：

```powershell
Copy-Item .\nba2k13.nro F:\switch\nba2k13\nba2k13.nro -Force
$a = (Get-FileHash .\nba2k13.nro -Algorithm MD5).Hash
$b = (Get-FileHash F:\switch\nba2k13\nba2k13.nro -Algorithm MD5).Hash
"local=$a card=$b"
if ($a -eq $b) { 'CARD_OK' } else { 'MISMATCH' }
```

**规矩**：

1. **不推半成品。** 一次把能修的修完再推，别让人反复插拔卡测。
   例外只有一种：某个修复**只能在真机上验证**（PC 上根本走不到那条路径），说清"电脑验证不了"再推。
2. **推完必须 MD5 铁验证**，本地 == 卡上。
3. **游戏运行时不要用 MTP 推文件**，会把 SD 写坏；先退出游戏。
4. 卡上只留**一个** NRO 入口。

MTP 通道（不想拔卡时）用 `tools/mtp-push-*.ps1`（Shell.Application COM），
注意 MTP 下 NRO 的显示名没有扩展名（`nba2k13`，类型 `NRO 文件`）。

## 4. 卡上的目录长这样

```
sdmc:/switch/nba2k13/
├── nba2k13.nro                 主程序
├── nba2k13.toml                配置（面板里点 Save to config 会覆写它）
├── NBA2K13_shaders.nfsp        着色器库（260 MB）
├── subpasos.txt                帧内子步骤（"3 1.0"）
├── game_root/                  游戏资产（你自己解包出来的）
├── logs/                       旋转日志 nba2k13_NNN.log
└── capturas/                   程序内截图
```

日志是**旋转**的（按大小切卷），出问题时不要只看最新那一个 —— 冻死/崩溃的证据常在上一卷的末尾。

相关日志：

| 文件 | 内容 |
|---|---|
| `logs/nba2k13_NNN.log` | 主日志（含所有 `[nativo]` 诊断行） |
| `logs/rex/rex_stderr.log` | SDK 层标准错误 |
| `logs/rex/rex_perfil.log` | 性能断面（fps、fences、绘制数、内存） |
| `logs/rex/rex_crash.log` | 崩溃栈 |
| `logs/rex/nativo.log` | 原生渲染器短日志 |

## 5. 配置（`nba2k13.toml`）

**字符串型 cvar 必须带引号**，数字不加：

```toml
NBA2K13_renderizador = "nativo"      # 字符串
nba2k13_nativo_tope_resueltas = 96   # 整数
nba2k13_nativo_mipmaps = true        # 布尔
```

关键项（当前实测配置）：

| 键 | 值 | 说明 |
|---|---|---|
| `NBA2K13_renderizador` | `"nativo"` | 切模拟/原生（**大小写敏感**） |
| `nba2k13_nativo_presenta_cinematica` | `true` | 电影双缓冲呈现（MV/回放必需） |
| `nba2k13_nativo_tope_resueltas` | `96` | resolve 缓存上限（防内存泄漏） |
| `nba2k13_nativo_sombras_escala` | `70` | 阴影图按 70% 画再放大（省内存/带宽） |
| `rex_fisico_sin_relleno_64mb` | `false` | **必须 false**，见 C41b |
| `nba2k13_nativo_perro_congelado` | `false` | 环看门狗，自愈会丢合法包 |
| `nba2k13_nativo_alias_color_cuadro` | `true` | C45 头像清色 |
| `nba2k13_nativo_c5g_respeta_swap_dibujado` | `true` | C48 兜底尊重 Swap |
| `nba2k13_nativo_resueltas_pisadas` | `true` | C47 |
| `captura_cada_s` / `captura_max` | `0` / `0` | **平时必须 0**，开了掉帧 |
| `volcar_destino_ancho` / `volcar_resuelta_ancho` | `0` / `0` | 探针导出，**平时必须 0** |
| `vulkan_validation_enabled` / `vulkan_log_debug_messages` | `false` | 开了会卡死 |

## 6. 调试面板

游戏内置 ReXGlue 设置面板，可以**运行时**开关每个 cvar，立刻看画面变化 ——
这是排查"这块画面是不是这个补丁管的"最快的手段。

| 平台 | 打开方式 |
|---|---|
| **Switch** | `L3 + R3 + 十字键右` |
| PC | `F4` |

- 上 = 性能叠层（PC `F3`）、下 = 日志窗口（PC `~`）、左 = 成就（PC `F7`）
- 面板移动用十字键 / 左摇杆；确认 = 下方键（索尼 ✕）、返回 = 右侧键（索尼 ○）；也可以直接触屏点
- `Nativo` 分类下就是本项目的全部开关

**两个提醒**：

1. **别点 `Save to config`** —— 它会立刻覆写 `nba2k13.toml`，把你在别处调好的配置冲掉。
2. 组合键是 `L3+R3`（摇杆按下）而不是 `L+R`，因为 2K13 里 `L+R+十字键` 是战术键，会冲突。
   这个键位与索尼/任天堂布局无关 —— 驱动直接读硬件。

## 7. 常见报错

| 现象 | 原因 |
|---|---|
| `biblioteca de shaders no disponible` | `.nfsp` 没放对位置，或容器格式解析不对（2005 vs 2008 版） |
| `DEVICE_LOST` | 着色器寄存器超 256 |
| `Heap exhausted!` @ `xmemory.cpp:1675` | guest 堆 512 MB 耗尽，看 `[C39] monton fisico` |
| 画面定格、GPU 利用率 0、CPU 100% | PM4 环死锁（C43 会打印 `anillo estancado`） |
| 掉帧且日志量大 | 探针没关（`volcar_*`、`captura_*`） |
| 改了 cvar 没反应 | 字符串没加引号，或该 cvar 只在启动时读一次 |
