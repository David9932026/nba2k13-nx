## GBAtemp

**版块**：`Switch - Software` → `Switch - Emulation, Homebrew & Backups`（或者 `Homebrew Projects`，看当天首页哪个更活跃）

**发帖形式**：New thread

- **Title**（一字不改，长度刚好）：
  `[WIP] NBA 2K13 (Xbox 360) native Switch port — plays full games at ~30 FPS, looking for a maintainer`
- **Prefix/Tag**：如果有 `WIP` 或 `Release` 选项，选 `WIP`
- **Body**：粘贴 `docs/POST-en.md` 从 `## Body` 下一行开始到 `---` 之前的全部内容

**注意**：

- GBAtemp 新账号前几帖会进审核，可能几小时才显示。别连发，等第一帖过审
- 那里的人会直接问"能不能给 NRO"——把 Release 链接甩过去就行
- 标题里有 `native` 这个词很重要，否则会被当成模拟器帖丢进别的版块

## Reddit

**有两个候选 subreddit，选一个发，不要同一天两边都发**（会被判 crosspost 刷屏）：

- `r/SwitchHacks` — 最对口，人多，容忍度高。缺点是标题党多
- `r/homebrew` — 更泛，但对"native port"这类项目接受度不错

**发帖形式**：`Create post` → **Images & Video** 标签页 → 上传 4 张图 + 在图下写正文（或者 Images 发完立刻用第一条评论补正文，看哪个版规要求）

- **Title**：
  `[NBA 2K13] Native Switch port — plays full games at ~30 FPS, six rendering bugs left, looking for a maintainer`
- **Flair**：`Development` / `WIP` / `Showcase`（按版块现有 flair 选最接近的）
- **Body**：`docs/POST-en.md` 正文

**注意**：

- **新号发长文 + 外链 = 90% 被自动删除**。至少要有几天历史、攒点 karma，否则先发一条短的（"working on a native 2K13 port, will post details in a comment"）再补充
- 不要用 Reddit 的 "crosspost" 从别的版搬过来
- 正文里别出现 `download`、`ISO`、`ROM` 这类词，容易被过滤器吃掉。用 `prebuilt binaries on the release page` 这种说法

## 贴吧

**吧**：`switch破解吧` 或 `switch吧`（前者对 homebrew 更友好）

**标题**：

`把《NBA 2K13》360 版搬上 Switch：能打整场、30 帧，剩下几个渲染坑想找人接手`

**正文**：`docs/POST-zh.md` 正文。贴吧对 Markdown 表格支持不好，粘贴后把表格改成一行一条：

```
能不能玩：能，整场比赛能打完
帧数：掌机模式大部分时间 30，比赛有段落掉到 ~20
本地双人：拆 Joy-Con 可用
...
```

**注意**：

- 图片用"添加图片"逐张上传，第一张放 `gameplay-ind-vs-ny.jpg`（能玩的证据）
- 贴吧会吞外链，把仓库地址写成 `github.com/David9932026/nba2k13-nx`（去掉 https:// 前缀），被吞就在楼中楼补一句"2楼回复里发地址"
- 首楼别把 Release 链接放最前面，容易被判定为广告

## 为什么这一步得你自己点

我没法替你注册账号发帖：

- 注册要邮箱验证码 + 人机验证（GBAtemp 还有人工审核），我没有你的邮箱和手机
- Reddit 新号发这种帖基本必被自动删除（spam filter 对"新账号 + 外链 + 长文"零容忍）
- 用马甲身份发帖违反两个站的规定，一旦被识别，牵连的是你本人的账号
